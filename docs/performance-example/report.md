# Synthetischer OBVR-Beispielbericht

Dieser Bericht ist absichtlich synthetisch. Er ist ein Formatbeispiel und kein
Ingame-Ergebnis. Zwei Szenenmarker zeigen 0,120 ms beziehungsweise 0,135 ms CPU-Wall
und zwei GPU-Intervalle von 0,120 ms beziehungsweise 0,140 ms. Daraus folgt keine
Bottleneck-Klassifikation; dafür braucht es wiederholte Läufe mit einem echten Spiel,
Headset und identischer Konfiguration.
