# its controller by the Iron Bow's (00025231) form weight; the string hand
# does not. The bow drawn from behind the left shoulder (as bow-hand.txt),
# held ahead, then the bow hand turned 40 degrees left in one frame and held:
# the drawn hand ("| O" in [Debug] HandLagTrace's lines) arrives later than
# the controller ("| L"), the weapon hand's columns (R) stay on its
# controller (the string hand never lags). A turn shows in the trace only as
# far as it moves the bone's target; the jerk after it is the plain read. That
# the arrow flies along the bow as drawn is checked in hand_mode_test ("the
# arrow along the drawn bow"); here no arrow is nocked. The bow's limb line for
# the block by contact is read off the drawn bow's node, so it is where the
# bow is drawn.
