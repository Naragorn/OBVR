# The world runs on as the tablet closes (Nadi's Windows run of 2026-11-27:
# "wenn ich das tablet schließe friert die welt ein paar frames ein";
# docs/inventory-tablet-spec.md 26.3). After the close the game keeps menu
# mode on while its menus fade out (about 17 frames at 72 Hz, 22 at 90 Hz)
# with only the HUD's menus in the stack; the world paused through them as
# behind any vanilla menu ("Menu pause: behind menu F1-F4 stack entry
# (0x001) the world pauses as vanilla" right after "Tablet: put down"). It
# runs on now, and the left stick walks on through them.
# The left B opens the inventory on the left hand's tablet; the left stick
# pushed forward walks the player under it; the left B closes it while the
# stick stays pushed; the walk's end ("Tablet: walked") comes once the fade
# is over. Before the change: the pause line at the close (the reject
# below) and the walk said at the close itself.
# The console takes its line for some seconds after a mark and eats the
# stick's keys meanwhile, so the walk waits 8 s after one, and no mark falls
# inside it. The walk's line says how far the feet went from the walk's
# start to the fade's end; against the DLL from before, the line comes at
# the close and the distance is that much shorter.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/tablet-close-runs.txt --headless --no-steamvr --parallel --plugin build-linux-clangcl/OBVR.dll
