# The hands stay in the game's menus ([Hands] HandsInMenus,
# camera/FrameLogic.h HandsAwayForMenus): the inventory opened with the left
# B - the hands stay, pinned and drawn over it (the stack's top reads as the
# F1-F4 entry, 0x001, not as Inventory); closed again; the Esc menu opened
# with the key - the hands go; closed - back as in the world. The "Hands: at
# the mark" line says what the render decided at each mark; the game-window
# pictures at "inventory" and "pause" show it.
# Run with: tools\hand-script-run.ps1 -Script tools\hand-scripts\hands-in-menus.txt

ini Hands Enabled=1
ini Hands HandsInMenus=1
ini Render MirrorMenusToMonitor=1

expect HandScript: finished
expect Hands: menu F1-F4 stack entry (0x001) - the hands stay - pinned and drawn as in the world
expect Hands: at the mark - menu 1 (F1-F4 stack entry), the hands shown, pinned 1
expect Hands: menu Pause (0x3F5) - the hands go
expect Hands: at the mark - menu 1 (Pause), the hands away, pinned 0
expect Hands: no menu - the hands as in the world
expect Hands: at the mark - menu 0 (none), the hands shown, pinned 1
reject HandScript: WARNING

wait 12
right pos 0.15 -0.25 -0.35
right rot 62 29 0
left pos -0.20 -0.40 -0.30
left rot 0 0 0
wait 1.5
mark world
left b 1
wait 0.2
left b 0
wait 2
mark inventory
left pos -0.25 -0.30 -0.35
wait 1
mark inventory_moved
left b 1
wait 0.2
left b 0
wait 2
mark closed
key 0x1B 1
wait 0.2
key 0x1B 0
wait 2
mark pause
key 0x1B 1
wait 0.2
key 0x1B 0
wait 2
mark back
wait 1
