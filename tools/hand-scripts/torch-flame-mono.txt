# The second control for torch-flame.txt: one world render a frame (Stereo=none),
# so no second walk with the frame clock zeroed - whether the flame animates
# then says if the dual pass is what stops it.
# The torch's flame in the hand mode (a Quest 3 tester's video, 2026-10-18:
# "torch animation ... doesn't work at all" - the flame's shape the same in
# every frame of thirteen seconds). Torch02 (0002CF9F, Lights\Torch02.NIF;
# the engine hangs Fire\FireTorchLarge.nif on its FlameNode1 - a
# NiFlipController over 20 textures a second, and the Fire and Sparks
# particle systems) is put in the left hand by the console and the hand held
# before the face; pictures at four marks two seconds apart. An animating
# flame shows a different flipbook frame in each picture (one chance in
# twenty of a repeat); a standing one the same shape in all four.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/torch-flame-mono.txt --run-timeout 300 --direct

ini Hands Enabled=1
# The torch equipped by the console comes into an open hand: no grace (TorchGraceSeconds, 2026-10-27).
ini Hands TorchGraceSeconds=0
ini Render Stereo=none
ini Render MirrorMenusToMonitor=1
console-at ready player.additem 0002CF9F 1
console-at ready player.equipitem 0002CF9F

expect HandScript: finished
expect a world frame while the game loads
reject HandScript: WARNING

wait 12
mark ready
wait 16
left pos -0.05 -0.30 -0.45
left rot 0 0 0
left curl 0.8
right pos 0.30 -0.40 -0.30
wait 3
mark torch-1
wait 2
mark torch-2
wait 2
mark torch-3
wait 2
mark torch-4
