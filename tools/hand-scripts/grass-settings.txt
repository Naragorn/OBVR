# The grass's reach and density from OBVR ([Render] GrassDistance and
# GrassDensity, game/GrassSettings.h): on a meadow west of the Imperial City
# the run starts with a reach of 2000 units and twice the game's grass (the
# spacing set before the save's grass is made), raises the reach to 8000 in
# the running game (ini-at; the head turns so the grass is built anew, which
# is when the game reads its distances), and then asks for four times the
# grass, which has to wait for the next start: the game's buffers stand.
# The measure is the "Grass: at the mark" line's patches under the Grass
# node (2026-11-06: 39 at 2000 units, 146 at 8000; 49 with the game's own

# between walls on the tester's Linux mod list, so the eye pictures show
# little of the meadow.
# Run with: tools/hand-script-run.py tools/hand-scripts/grass-settings.txt --headless
