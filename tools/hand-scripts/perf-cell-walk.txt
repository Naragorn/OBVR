# The hitches a tester feels outdoors (avolpe, 2026-10-24: a stutter about
# every five minutes outdoors), measured where they would come from: the
# player walking back and forth across an exterior cell border, with the
# profiler, the render sampler and the compositor's half-rate watch. Each
# crossing makes the engine shift its loaded grid (uGridsToLoad=5: a row of
# five cells attached, one detached; bBackgroundCellLoads=1 on both
# installs) - whether every crossing does, or only past some margin, is
# what the capture shows. The house exit is perf-cell-border.txt.
#
# The harness walks at about 40 units a second (grass-turn: 215 units in
# 6 s), so a straight walk crosses a 4096-unit cell in well over a minute.
# Instead the player stands on a cell corner - "cow Tamriel -13 21" puts
# them at -53248 86016, the south-west corner of cell (-13, 21), an open
# meadow (grass-turn's) - faces west, and walks ten seconds west and ten
# back, four times: eight crossings of the border at x = -53248. The walk
# follows the head's heading, so "head yaw 180" turns round without the
# console (the console eats the sticks for about 8 s after a console-at).
# A mark logs the player's place ("Combat ring: ... from the player at
# x y"), which tells the cell. The capture is armed with the game and starts
# StartAfterSeconds later, about 20 s after the script's clock, so it opens
# before the first leg and closes inside the last wait.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/perf-cell-walk.txt --headless --run-timeout 420
