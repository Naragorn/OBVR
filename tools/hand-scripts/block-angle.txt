# The block's angle ([Hands] BlockByAngle, game/BlockAngleLogic.h, the veto
# in game/BlockCone): a melee bandit (00069AD1) attacks an untouchable player
# (tgm - the hit handler still runs), the head facing it (head face 1), a
# longsword drawn by the holster and raised as a guard - first level across
# the body, then upright - each held half a minute. Every blow the engine
# would block is judged at the blow: "Block angle: a blow from ... at the
# weapon - the blades, N degrees (at least 60) - blocked / THROUGH"; the
# state lines at the marks show the player blocking (the guard holds with
# the blade either way, since the rule decides at the blow). Which verdicts
# come depends on the bandit's swings; the run shows the angles read.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/block-angle.txt
#      or:  tools\hand-script-run.ps1 -Script tools\hand-scripts\block-angle.txt

ini Hands Enabled=1
ini Hands Holsters=1

console-at ready player.placeatme 00069AD1 1

expect Hands: ready weapon done
expect Block: the block cone rerouted
expect Block angle: a blow from
expect at the weapon - the blades
