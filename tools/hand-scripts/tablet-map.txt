# The map page on the tablet: the inventory opens on the tablet, then F4 (the
# Map page) by its key. The map's extension is wider than the page, so the crop
# widens (docs/inventory-tablet-spec.md 7). Wanted: "Tablet: the Map page read"
# with its crop; eye pictures (EyeDump) at the marks.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/tablet-map.txt --headless --no-steamvr --parallel

ini Hands Enabled=1
ini Tablet Enabled=1
ini Tablet Unroll=vertical
ini Hands LeftHandGripX=0
ini Hands LeftHandGripY=0
ini Hands LeftHandGripZ=0
ini Hands HandGripUpMetres=0
ini Hands HandGripForwardMetres=0
ini Tablet InScene=1
ini Render UnpausedMenus=0
ini Render MonitorMenusOnly=0
ini Debug EyeDump=1

expect HandScript: finished
expect Tablet: the Inventory page read
expect Tablet: the Map page read
reject HandScript: WARNING

wait 12
left pos -0.12 -0.32 -0.32
left rot 0 0 0
right pos 0.15 -0.25 -0.15
right rot 40 25 0
wait 1.5
left b 1
wait 0.2
left b 0
wait 2
mark inventory
key 0x73 1
wait 0.2
key 0x73 0
wait 2.5
mark map
wait 1
mark map2
