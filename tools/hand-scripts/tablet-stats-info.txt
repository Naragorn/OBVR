# The stats page's own info box on the tablet (docs/inventory-tablet-spec.md
# section 22; Nadi, 2026-11-25: "die infobox erscheint im stats tab für ein
# paar Einträge du hast die nur abgeschnitten ... den stats tab verbessern
# sodass die infoboxen wieder sichtbar sind und nicht abgeschnitten"): the
# tablet in the left hand, the thumb up and the palm to the eyes, the stats
# page turned to; each of its first three tabs chosen by its icon with the
# right hand's beam and trigger, then the beam stepped down the tab's rows,
# resting 1.1 s on each step, so the hovered row's description slides out
# beside the page and stands (each film begins with the beam still on the
# tab's icon: the first box slides out half a second in). The box is the
# stats menu's own picture (the tile of id 61), not the MagicPopup menu: the
# log says "Tablet: the page's own info box shown beside the page". The DLL
# from before cuts the face at the page's edge: the rows highlight and no box
# is seen. The right hand stands near the right eye, out of the picture, so
# its beam meets the page nearly square on.
# The beam's angles are measured, not reckoned: a grid of
# angles run once (tablet-aim-grid.txt), the laser's hit read at each mark's
# state line and fitted, then asked for the tabs' icons and the rows' column
# by their places in stats_menu.xml (tools/tablet-aim.py --stats: the icons
# 135 wide from 28, 165 and 304 at 631 down the 745 by 792 page). A DLL from
# before section 21 holds the page 7.8 cm deeper and needs its own aim.
# Films from each mark, the eye cut to the page and the box.
