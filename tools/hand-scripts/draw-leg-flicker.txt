# The legs as the weapon is drawn (docs/player-body-spec.md, the open bug
# "the legs flicker as the weapon is drawn"; the tester's Windows run of
# 2026-11-05): the body shown, looked down at, a longsword drawn at the left
# hip with the grip held (WeaponHold as the player has it), kept four
# seconds, sheathed at the hip, and the same twice more. Debug.BodyTrace
# logs the body every frame with each leg's foot and knee against the root;
# tools/draw-leg-flicker.py reads, window by window between the marks, how
# far the feet and the knees move from one frame to the next and how often
# a foot's solve switches on and off. With the player standing nothing of
# the legs may jump: [Body] IKStanceSpeed (60 units a second) holds the feet
# to the speed the game's own draw reaches, and the solve is eased in and
# out. tools/draw-leg-flicker.py <run> --most-step 1.2 --most-flick 1.2
# --most-still 0.3 fails the run when a foot goes further through a draw, or
# a foot or knee while standing.
# The view itself (2026-11-10, camera/StandingEyeHold.h): tools/body-motion.py
# <run> --gate draw*:camstep<=0.1 --gate sheathe*:camstep<=0.1 - the camera's
# largest move in a frame while the head is still (0.5 before).
# Run with: tools/hand-script-run.py tools/hand-scripts/draw-leg-flicker.txt --headless

ini Hands Enabled=1
ini Hands Holsters=1
ini Body Visible=1
ini Debug BodyTrace=20000
console-at ready set timescale to 0
console-at ready set gamehour to 12
console-at ready fw 00038EEE
console-at ready player.additem 00000C0C 1
console-at ready player.equipitem 00000C0C

expect HandScript: finished
expect Body IK: the third-person skeleton - 27 of 27 bones found
expect Body IK: the trunk's pose taken from the standing idle
expect Body IK: a foot held to the stance's speed
count 3 Holster: reach for the one-handed weapon
count 2 let go at the left hip - sheathed and kept there
reject HandScript: WARNING
reject draw given up

wait 12
right rot 0 0 0
right pos 0.20 -0.40 -0.30
left rot 0 0 0
left pos -0.20 -0.40 -0.30
head pitch -45
wait 1
mark ready
wait 10
mark sheathed
wait 3
dump

mark draw1
wait 1

wait 0.3
right grip 1
wait 0.2
right pos 0.20 -0.45 -0.30
wait 4
mark held1
wait 3
dump

wait 4

wait 3

wait 1
