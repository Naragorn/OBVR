# The script clock ([Debug] ScriptTimeTrace, game/ScriptClock.h) over the
# two hitches of docs/performance-spec.md section 6: the house exit of
# perf-cell-border.txt (the first world frame after the load took 158.7 ms,
# 77 % of it in xOBSE's script token reader) and the first two legs of
# perf-cell-walk.txt across the corner of cell (-13, 21) (107.8 ms on the
# second leg). The clock names the scripts by form ID; the profiler runs over
# the house exit beside it, so the clock's frame line can be matched by its
# tick to the long frame in frames.csv and its milliseconds to the
# sampler's share.
#
# Weynon Priory's house, then the stall outside by player.moveto (a load like
# a door's), half a minute standing; the house again and out again, to see
# whether the second exit in the same session costs what the first did (the
# harness save is older than Maskar's Oblivion Overhaul, so the first entry
# into Tamriel is that mod's first in this save); then "cow Tamriel -13 21"
# (another load) onto the meadow corner, facing west, ten seconds west, ten
# east, ten west. The console eats the sticks for about 8 s after a
# console-at, hence the ten seconds before the first leg; the walk follows
# the head's heading, so "head yaw 180" turns round.
# 2026-10-25 17:36 (one exit only): PASS; the exit's first world frame
# 160.4 ms, 137.0 ms of it scripts, 127.4 ms in one run of 0D58EC96 (MOO's
# MOOUpdateWorldSpacesAddNewFunctionScript).
# 2026-10-25 18:12: PASS; the first exit 168.7 ms (130.2 ms of the same
# script, then 165.6 ms of MOO's outpost functions 0.27 s later), the second
# exit 120.8 ms with 105.0 ms of it the moveto's load and nothing of MOO's.
