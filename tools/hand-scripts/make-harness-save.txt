# Not a test: writes the save the scenarios start from (OBVRHarness.ess, next
# to the player's own saves, which it leaves alone; the runner keeps it the
# oldest save outside its runs, so the player's Continue never lands in it).
# It starts from the player's last save, goes to TestingHall, empties the
# pack, gives an Iron and a Steel Longsword, equips the steel one sheathed,
# and saves under its own name. Run it once, and again whenever that save is
# lost. The player's last save had the weapon drawn (2026-09-27); the right
# hand's reach to the left hip puts it away (OBVR's holster - the F key no
# longer did under Full VR, 2026-10-01), and the state line at "sheathed" must
# read weapon 1 (sheathed).
# Run with: tools\hand-script-run.ps1 -Script tools\hand-scripts\make-harness-save.txt -Save continue

ini Hands Enabled=1
ini Hands Holsters=1
ini Render MirrorMenusToMonitor=1
console coc TestingHall
console-at arrived player.removeallitems
console-at arrived player.additem 000229B3 1
console-at arrived player.additem 00000C0C 1
console-at arrived player.equipitem 000229B3
console-at sheathed save OBVRHarness

expect HandScript: finished
expect weapon 1 (slot 1), active menu none
reject HandScript: WARNING

wait 12
mark arrived
wait 25
right pos -0.18 -0.62 -0.02
wait 0.3
right grip 1
wait 0.2
right grip 0
right pos 0.20 -0.40 -0.30
wait 3
mark sheathed
wait 12
