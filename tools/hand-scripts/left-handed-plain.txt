# The control for left-handed-mirror.txt: left-handed with the mirror off
# ([Hands] LeftHandMirror=0, the picture before 2026-10-20 - the game's
# right hand on the left controller), the same poses and marks. The mark
# line must read "the first-person skeleton as the game has it: root
# determinant 1" with both hand bones' determinants 1, and no cull swapped;
# its Camera01 and eyes are what the mirrored run is compared against.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/left-handed-plain.txt --run-timeout 240 --headless

ini Hands LeftHanded=1
ini Hands LeftHandMirror=0
ini Hands HandsInMenus=1

expect HandScript: finished
expect Hands: at the mark - the first-person skeleton as the game has it: root determinant 1

left pos -0.25 -0.30 -0.40
wait 2

right pos 0.15 -0.10 -0.35
left pos -0.15 -0.10 -0.35

left rot -30 0 0
wait 2
mark raised
head yaw 40

wait 1
