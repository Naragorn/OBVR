# A real death with [Hands] FirstPersonAfterKnockdown on: the player not
# essential and Oblivion Combat Extender's death replacer off (its main
# script would make the player essential again each frame otherwise), then
# killed. The death view holds in third person and nothing switches the view
# back while the player is dead - the knockdown stays "down" until the next
# load (camera/FrameLogic.h, StepFirstPersonAfterKnockdown).
# Run with: powershell -ExecutionPolicy Bypass -File tools\hand-script-run.ps1 -Script tools\hand-scripts\real-death.txt -Direct -Save OBVRHarness

ini Hands Enabled=1
console-at ready stopquest MQ01
console-at ready set xLDDenied.setPlayerEssential to 0
console-at ready set xLDDenied.deathReplacerActive to 0
console-at ready setessential 00000007 0
console-at placed player.kill

expect HandScript: finished
expect Camera: switched to third person (frame
expect Camera: the death view is held still
expect Hands: knocked down (knock state
reject Hands: up after the knockdown and still in third person
reject Camera: switched to first person (frame
reject HandScript: WARNING

wait 12
right rot 0 0 0
right pos 0.20 -0.40 -0.30
left pos -0.20 -0.40 -0.30
wait 1
mark ready
wait 3
mark placed
wait 3
mark dead-3
wait 5
mark dead-8
wait 5
mark dead-13
