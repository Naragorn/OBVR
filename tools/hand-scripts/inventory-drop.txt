# The inventory's drop (docs/controls-spec.md 1, "In a game menu"): the left A
# in the inventory drops the item under the cursor - one per press, however
# long it is held (2026-09-27: one press had dropped two and three items when
# the inventory flickered to the HUD and back after a drop). Nadi 2026-11-13:
# "A links ging nicht mehr". The pointer is aimed as in inventory-pointed-item.txt
# (the first row, index 0 - the save's Elven Longsword, one of it); each mark
# logs "Inventory: under the pointer index n - <name>", so the first row
# naming another item (or none) after the press is the drop, and "HandScript:
# items" names the dropped sword as the nearest item to the eyes. Each press is
# logged with what it did ("Inventory drop: the left A in the ... menu").
# 2026-11-13 on Linux (DLL c56e7054): the Iron Longsword left the first row and
# a new reference FF000F83 (a weapon) lay 102 units ahead - the drop works here.
# Run with: python3 tools/hand-script-run.py --headless tools/hand-scripts/inventory-drop.txt

ini Hands Enabled=1
ini Render MirrorMenusToMonitor=1

expect HandScript: finished
expect Inventory: under the pointer index 0
count 1 Inventory drop: the left A in the Inventory menu - Shift and a click on the item
count 1 Hands: click sent to the Inventory menu
reject HandScript: WARNING

wait 12
right pos 0.15 -0.25 -0.35
right rot 62 29 0
left b 1
wait 0.2
left b 0
wait 1.5
mark inventory
wait 1
mark before_drop
# One press, held long: one drop.
left a 1
wait 1.5
mark held
left a 0
wait 1.5
mark after_drop
left b 1
wait 0.2
left b 0
wait 1.5
mark closed
