# The shield through a draw and a sheathe (Nadi, Windows 2026-11-27/28: "the shield, when equipped, still flickers
# around in the hand when I draw or sheathe the weapon", "schilde wackeln noch in der hand"; free-weapons-spec, "The
# shield held to the hand"). The shield and a sword equipped, the left hand held still in front, the sword drawn and
# sheathed twice by the ready key. Since 2026-11-28 the fix's check (game/ShieldHoldLogic.h): the shield's rest is
# taken while the arm stands at rest ("Shield hold: the shield held to the left hand from now on"), and each of the
# four "Arm draw trace:" lines must end its shield part with "held still on the hand" - the twist bone (the shield's)
# under 0.1 units and 0.5 degrees a frame against the pinned left hand, while "the hand's local (the animation's)"
# still turns by the draw's degrees. Before the fix (main 40b7b34) the same lines read 0.6 to 5.9 units a frame,
# "SWUNG on the hand". Film it with --record 12 and the head turned to the left hand to see it.
# Written 2026-11-28, not run yet.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/shield-draw-trace.txt --headless --no-steamvr --parallel --plugin build-linux-clangcl/OBVR.dll

ini Hands Enabled=1
# The harness save's question box closed first.
console-at settle CloseAllMenus
console player.additem 000733ED 1
console player.equipitem 000733ED
console player.additem 00000C0C 1
console player.equipitem 00000C0C

expect HandScript: finished
expect Hands: a shield worn - the raised left hand blocks
expect Shield hold: the shield held to the left hand from now on
count 2 Arm draw trace: through the draw (a shield worn 1)
count 2 Arm draw trace: through the sheathe (a shield worn 1)
count 4 held still on the hand
reject SWUNG on the hand
reject Shield hold: the shield's bone hangs under
reject HandScript: WARNING

wait 20
mark settle
left pos -0.20 -0.35 -0.30
left rot 0 0 0
right pos 0.20 -0.45 -0.25
wait 2
mark ready
key r
wait 2
mark drawn
key r
wait 2
mark sheathed
key r
wait 2
mark drawn_again
key r
wait 2
mark sheathed_again
