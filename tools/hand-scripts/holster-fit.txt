# The weapon places' fit (docs/controls-spec.md 4.1, 4.2): started as its
# settings row would, the weapon hand's trigger takes the melee place, the

# The run writes the places to OBVR-test.ini, never to OBVR.ini.

ini Hands Enabled=1
ini Hands Holsters=1
console player.additem 00000C0C 1

expect HandScript: finished
