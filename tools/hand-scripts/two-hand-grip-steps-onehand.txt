# 2026-11-10: as in Half-Life: Alyx the hand comes near the handle but does
# not take it before the grip is pressed; the grip's pull closes it the rest
# of the way. 2026-11-11: more and earlier - TwoHandCloseAt 0.55). The
# Iron Claymore, the left hand at its handle with the grip's pull 0, 0.1

ini Hands Holsters=1
ini Hands TwoHandGrip=1

console-at ready CloseAllMenus
console-at ready set timescale to 0
console-at ready set gamehour to 12
console-at ready fw 00038EEE
