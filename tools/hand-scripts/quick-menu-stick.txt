# The sticks' buttons without a trackpad (docs/controls-spec.md 4.4; the
# tester, 2026-10-15: "rechter stick halten -> warte menü. kurz quickmenü.
# links same mit halten -> quest menü"): a short right click opens the ring
# latched, the hand moved right lights slot 3, the next click uses it; the
# right button held past StickHoldSeconds opens the Rest menu (SleepWait), and
# the right B closes it with the menu's own key. The left stick is the walk's
# alone.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/quick-menu-stick.txt

ini Hands Enabled=1
ini Hands QuickMenu=1
console player.additem 00000C0C 1
console SetHotkeyItem 3 00000C0C

expect HandScript: finished
count 1 QuickMenu: opened at the hand
expect the quick menu's picture saved as OBVR-QuickMenu-ring_open.bmp
expect the quick menu's picture saved as OBVR-QuickMenu-slot3_lit.bmp
expect QuickMenu: hotkey 3 used
count 1 Hands: at the mark - menu 1 (SleepWait)
count 1 Hands: menu SleepWait (0x3F4)
reject Hands: menu Pause (0x3F5)
reject HandScript: WARNING

# Time for the runner to type the console lines and the console to close.
wait 16
mark standing
right pos 0.15 -0.30 -0.35
wait 0.3
# A short click: the ring, latched.
right click 1
wait 0.12
right click 0
wait 0.6
mark ring_open
# Right of where it opened: slot 3.
right pos 0.23 -0.30 -0.35
wait 0.4
mark slot3_lit
# The next click lets go: slot 3 used.
right click 1
wait 0.12
right click 0
wait 1.5
mark after_use
# Held: the Rest menu.
right pos 0.15 -0.30 -0.35
wait 0.3
right click 1
wait 0.9
right click 0
wait 1.0
mark rest_menu
right b 1
wait 0.2
right b 0
wait 1.5
mark rest_closed
wait 1
