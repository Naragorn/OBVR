# Loading a save in-game by the laser (a Quest 3 tester, beta 6, 2026-10-22:
# "when trying to load a save file in-game, the issue with hitting the button
# remains"): Escape opens the pause menu, whose buttons load-menu-map.txt
# measured on the quad at yaw 5 (24.5 pixels a degree of pitch): Return at
# pitch 64 (y 552), Save 61 (636), Load 55 to 58 (717 to 795), Options 52
# (870), Quit 49 (945). The trigger pulled on Load (a button menu: the click
# on the pull) opens the Load menu (0x40E, a touch-press menu: the click on
# the release, a drag of 2 % of the layer's height a scroll). Its list is
# then mapped the same way - the tile under the cursor at each mark, yaw +12
# for the saves on the left (a negative yaw points right: yaw -12 read
# "load_background" at x 1705 on the first run, 11:39) - and the first save
# aimed is clicked with the
# hand held still: the release on the same pixel is the click, and the
# game's confirmation box ("Hands: menu Message") is the proof. A map first:
# the save's pitch is a guess until the marks say where the list is.
# Run with: python3 tools/hand-script-run.py tools/hand-scripts/load-menu-click.txt --run-timeout 240 --headless
