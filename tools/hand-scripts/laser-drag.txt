# Drags with the laser placing the cursor (docs/controls-spec.md 4.37; the
# tester, 2026-10-10: "slider kann man nicht ziehen. sidebar scrolls auch
# nicht. die map im Tab menü auch nicht"). The map, opened with F4: the
# trigger pulled on it holds the button at once, the beam moved drags - the
# engine's own cursor walked after the beam by mouse steps, nothing written
# over it meanwhile - and the map pans (the pictures before and after).
# Run with: tools\hand-script-run.ps1 -Script tools\hand-scripts\laser-drag.txt

ini Hands Enabled=1
ini Render MirrorMenusToMonitor=1

expect HandScript: finished
expect Hands: a drag held in the Map menu
expect Hands: the drag let go
expect the map's pan from
reject HandScript: WARNING

wait 12

right rot 62 24 0
key 0x73 1
wait 0.2
key 0x73 0
wait 2
mark map
right rot 60 22 0
wait 1
mark aimed
right trigger 1
wait 0.3
mark pulled
right rot 59 21 0
wait 0.05
right rot 58 20 0
wait 0.05
right rot 57 19 0
wait 0.05
right rot 56 18 0
wait 0.05

wait 0.05
mark dragging

wait 0.05
right rot 53 15 0
wait 0.05
right rot 52 14 0
wait 1
mark dragged
