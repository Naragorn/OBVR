# The bow held upright in front blocks (vr::IsBowGuard; the tester,
# 2026-10-01: "dass man mit bow blocken kann wenn ich den senkrecht vor mir
# hochhalte"), as the bow blocks in vanilla. The bow is drawn from behind the
# left shoulder, raised upright before the eyes (the controller turned up 90
# degrees: the bow stands upright, as in bow-by-hand), then laid flat, then
# raised again and lowered; an arrow taken from the quiver ends the guard.
# Run with: tools\hand-script-run.ps1 -Script tools\hand-scripts\bow-block.txt

ini Hands Enabled=1
ini Hands Holsters=1
ini Hands BowByHand=1
console player.additem 00025231 1
console player.equipitem 00025231
console-at arrows player.additem 00017829 20
console-at arrows_on player.equipitem 00017829

expect HandScript: finished
expect Hands: the bow is held upright - blocking
expect Hands: the left hand is down - block released
expect Hands: bow by hand - an arrow taken from the quiver
reject HandScript: WARNING

wait 16

wait 3
mark arrows_on
wait 12

left grip 1

wait 3

dump
wait 1
left rot 0 0 0
wait 1
mark flat
dump
wait 1
left rot 90 0 0
wait 1
mark upright_again
right pos 0.15 -0.10 0.12
wait 0.3
right trigger 1
wait 0.5
mark arrow_taken
